시상 효과음 파일을 여기에 넣으세요.

파일명(둘 다 mp3/m4a/wav/ogg 아무 확장자나 됨):
  drumroll.mp3  ← 티저(수상자 공개 직전) 긴장감 드럼롤
  reveal.mp3    ← 공개 순간 팡파레/승리 효과음

동작:
- 이 파일이 있으면 awards.html이 "진짜 소리"로 재생합니다.
- 파일이 없으면 코드 합성음(폴백)이 나옵니다.

주의:
- 파일 재생은 인터넷 서버로 열어야 로드됩니다 → 폴더에서 `npx serve .` 후
  http://localhost:3000/awards.html 로 여세요. (파일을 그냥 더블클릭하면 브라우저
  보안상 효과음 파일을 못 읽어 합성음으로 폴백됩니다.)
- 무료·저작권프리 음원 추천: mixkit.co/free-sound-effects (로그인 없이 다운로드),
  pixabay.com/sound-effects. 검색어: "drum roll", "fanfare", "orchestra hit", "win".
- 길이 권장: 드럼롤 2~4초, 공개 팡파레 1~3초.
